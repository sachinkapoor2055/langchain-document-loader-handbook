# LangChain Document Loaders

A hands-on collection of Jupyter Notebook notes and examples for learning LangChain's Document Loader component.

This repository explores how LangChain loads data from different sources and converts it into standardized `Document` objects that can be further processed, split, embedded, stored, and used in LLM applications.

## 📚 Topics Covered

- Document Loader Architecture
- Text File Loading
- CSV File Loading
- JSON File Loading
- PDF File Loading
- Web Page Loading
- LangChain Document Objects
- Metadata and Document Content

## 📂 Notebooks

| # | Notebook | Description |
|---|---|---|
| 0 | `document_loaders_overview.ipynb` | Overview of LangChain Document Loaders and the `Document` abstraction. |
| 1 | `text_loader.ipynb` | Loading and processing plain text files with LangChain. |
| 2 | `csv_loader.ipynb` | Loading CSV data and converting rows into LangChain documents. |
| 3 | `json_loader.ipynb` | Loading structured JSON data and working with it as documents. |
| 4 | `pdf_loader.ipynb` | Extracting content from PDF files and converting it into documents. |
| 5 | `web_loader.ipynb` | Loading and processing content from web pages as LangChain documents. |

## 🎯 Learning Objective

The goal of this repository is to develop a practical understanding of LangChain's Document Loader ecosystem and learn how different data sources can be prepared for downstream LLM workflows.
